# Durian Management System

A PHP-based web application for efficient durian farm management. This system provides tools for tracking harvests, sales, costs, inventory, and detailed tree health information.

## Core Functionalities:

*   **Data Input:** Farmers can log sales, costs, inventory counts, and tree conditions (including fertilization schedules).
*   **Reporting & Analytics:** Generate insights into financial performance, tree health trends, and operational efficiency through various reports and visual dashboards.
*   **Tree Maintenance:** Monitor individual tree health and track fertilization history to ensure optimal growth and yield.

This project utilizes a combination of:
*   **Backend:** PHP
*   **Database:** MySQL
*   **Frontend:** HTML, CSS, JavaScript 

The goal is to provide a user-friendly interface for managing complex farm data, leading to improved decision-making and farm productivity.
